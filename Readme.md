# 🔤 Unique String Adder Web App

This is a simple web app that allows users to enter unique strings.  
It checks if the entered string is already in the list before adding it, and then displays the **sorted array** and its **length**.

---

## 🌐 Live Demo

🔗 [Click here to try it live](http://ulaganathan0709.github.io/Array/)
---

## 🛠️ Features

- ✅ Add unique strings to an array
- ❌ Duplicate entries are not allowed
- 🔠 Automatically sorts the array alphabetically
- 📏 Shows the **length** of the array
- ✨ Alerts user on success or duplicate
